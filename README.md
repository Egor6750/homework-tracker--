# Трекер домашних заданий (MVP)

## Пользователь
Студент вуза или колледжа, который одновременно ведёт несколько учебных дисциплин и хочет контролировать сроки сдачи работ.

## Проблема
Задания выдаются в разных чатах, на портале и на парах, из-за чего легко забыть о дедлайне или потерять описание работы.

## Гипотеза
Если собрать все домашние задания в едином списке с фильтрацией по статусу и счётчиком времени до дедлайна, студенты будут сдавать работы вовремя и без стресса.
