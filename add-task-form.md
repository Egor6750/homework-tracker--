# Добавление нового домашнего задания

## Поля формы
- **Предмет:** выпадающий список дисциплин семестра
- **Описание задания:** текстовое поле для сути работы и ссылок
- **Дедлайн:** выбор даты и времени сдачи

## Действия
- Кнопка **«Сохранить задание»** — добавляет запись в общий список
- Кнопка **«Отмена»** — очищает поля и возвращает на главную страницу
